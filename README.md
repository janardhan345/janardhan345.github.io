Personal portfolio site built with vanilla HTML, CSS, and JavaScript.

https://janardhan345.github.io/pfv3

## Sections
- **About** — background and highlights of the projects I've built.
- **Projects** — CANSAT GUI, IMDF, and FTTA with links to code and live demos.
- **Blog** — write-ups on pattern thinking, how I built the CANSAT GUI, and my take on using AI to code.

## Projects featured
- **Satellite GUI** — real-time telemetry dashboard (Node.js, Socket.IO, PostgreSQL) for an ISRO CANSAT competition.
- **Image Meta Data Filter (IMDF)** — API to upload and filter images by metadata.
- **Faculty Time Tracking Application (FTTA)** — full-stack app with RBAC via Passport.js + Google OAuth 2.0, in use by 500+ users.
