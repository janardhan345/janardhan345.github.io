Welcome to my portfolio. I'm a passionate backend engineer.

Hi, my name is Janardhan. I'm a backend engineer who builds applications that solve real-world problems, and I love to talk about how software should make users genuinely want to pay for it because they think it truly deserves to be paid for. Should We Use AI to Code? ↩

Built a GUI for a mini satellite (CANSAT) to receive telemetry data and visualize it in real time using Node.js (Socket.IO), while storing telemetry values in PostgreSQL for further analysis and research. It was developed for a competition organized by ISRO and made it to the finals at the UP launch station. The application runs locally hosted and cannot be deployed. Developed an API that lets users upload, store, and filter images based on metadata (deployed on Render).

Built a full-stack application accessible only from allowed organization domains, letting admins monitor faculty availability and sessions while faculty log their sessions and student details. Implemented RBAC through Passport.js and Google OAuth 2.0 (currently in use with 500+ users, deployed on Heroku + Neon DB).
